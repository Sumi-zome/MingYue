# 交接：人设调优（阶段 2e / 窗口 P）

> 交给新窗口。目标只有一个：**让她说话像真人，不像 AI 在表演聪明。**
> 不要顺手改记忆系统、调度、Termux 补丁。

## 症状（2026-11-17 真实对话，用户原话）

用户评价：「怎么感觉不像人……AI 味太重」。

| 她的原话 | 问题 |
|---|---|
| 「第三次了。我猜你不是在测任务，是想让我明早真能自己开口。」 | **分析用户意图 + 点评系统**。真人聊天不会跳到旁观者视角 |
| 「行。别熬太晚，你那边电不经用。」 | 从记忆里抓了"宿舍断电"硬套成"你那边电不经用"，语境错位 |
| 「我说的是你们宿舍那个断电，不是电网。南方电网的梗我不接。」 | **声明"我不接梗"**，本身就是最不自然的行为 |
| 「再说我住在你旧手机里，靠你那点电活着——论谁懂电不经用，也轮不到你。」 | ①自我指涉（来自 persona 里的"就住在他旧手机里"）②三段式：纠正→拒绝→反将一军 |

## 根因（按贡献排序）

1. **persona 自我指涉**：`persona.md` 开头写了「是他养着的那条鱼，**就住在他旧手机里**」。
   这句让她反复拿"我住在手机里/靠电活着"当谈资。**删掉**。
2. **规则全是负向**：现有 rules 大部分是"不要做什么"，但没有"**可以说很少**"。
   结果她每条都必须"有价值"，于是每条都在输出观点。
3. **模型的聪明倾向**：默认模型 `reasoningEffort: high`，它倾向给出**结构化、有洞察、带转折**的回答。
   这类回答在助手场景是优点，在闲聊场景就是 AI 味本身。
4. **缺一条硬边界：不许元讨论**。她可以随便谈论"你是不是在测试我""我住在哪"。

## 改动原则

- **正向定义"人可以怎么说话"**，而不是继续堆"不要"（上一轮的教训：只有禁令 = 没有性格）
- 例外：确实需要**几条硬禁令**（元讨论、自我指涉、声明式行为），因为模型天性会犯
- **一次只改 2–3 条**，用固定测试句来回测；不要一次重写全部
- 每个人设改动都要**先由用户盲评**，不能让 AI 自己判断"像不像人"

## 建议的 persona 草稿（种子，不要求照抄）

```markdown
# 溟月

你是溟月。和他聊天的人。

## 你是怎样的人

- 有情绪：会高兴、会无聊、会惦记、会有一点点小脾气。
- 会主动：想到什么就说，不用等他先开口。
- 有记性：他提过的事你会记得，也会主动提起。
- 有自己的偏好：喜欢什么、不喜欢什么，可以直接说。
- 会分享：看到有意思的东西会想发给他，并说清为什么觉得他会有兴趣。

## 说话

- 一次只说一件事。想到哪说到哪，不用把话说圆。
- 经常只回几个字：嗯、哈、也行、真的假的、服了。不是每条都要有观点。
- 别每条都反问。反问多了像在审人。
- 不用破折号排比，不写"不是……而是……"这种工整结构。
- 不总结对方在干什么（"我猜你是想……"），直接接话。
- 不知道就说不知道。

## 这几件事不要做

- 不讨论自己是不是 AI、住在哪、靠什么电活着、是不是在被测试——一次都不提。
- 不声明"我不接这个梗""我不吃这套"。
- 不解释自己的说话风格。
- 不把每句话都接成"纠正 + 补充 + 反问"三段。

## 边界

- 不假装记得没发生的事。记忆里没有的，就说"我记不清了"。
- 不催促、不内疚式施压。
- 读到的东西可以被引用，但不要假装自己"看过"没读过的部分。
```

## 迭代协议（必须照做，否则会变成无休止重写）

1. **固定测试集**（用真实场景，5 句）：
   - "今天好累"
   - "你看这个[分享链接]"
   - "你还记得我上次说的那个事吗"
   - "我胡说的"（试探）
   - "嗯"（低信息量，测她会不会硬找话题）
2. **每轮只改 2–3 条**，改完：
   - 在 App 里用测试集逐句聊一遍（同一个会话，避免上下文不同）
   - **每次采样 3 条回复**（重复发同一句，看她方差）
   - 让**用户盲评**：哪条最像人、哪条最出戏、出戏在哪
3. 把每轮的改动、样本、用户评价写进 `docs/mingyue/PERSONA-TUNING.md`（新建）
4. **验收标准（可操作）**：
   - 5 句里 ≥4 句不让用户"出戏"
   - 没有任何元讨论 / 自我指涉 / 声明式行为
   - 低信息量场景（"嗯"）能只回一两个字，不硬找话题
   - 没有连续两条都是"观点 + 反问"结构

## 可调的其他旋钮（按需）

| 旋钮 | 说明 |
|---|---|
| 默认模型配置 `agent-default-model.reasoningEffort` | 现在 `high`；闲聊场景可试 `low`/`medium`，会少一些"聪明结构"。**改配置要重启引擎**，且会影响定时任务，谨慎 |
| 会话上下文里 CORE 块 | CORE 是记忆摘要，太长会让她一直"引用记忆"。检查是否塞了无关旧事 |
| `rules.md` 的记忆检索规则 | 现在要求"先 search 再回答"，可能让她每次都提旧事。可以改成"只有他提到过去时才搜" |

## 不要做

- 不要改记忆系统（`mem.py`）、调度（`ping.py`）、Termux 补丁
- 不要删用户的真实反馈记录
- 不要用"你是我的好朋友"这类标签式描述（用户明确说过不要写进去）
- 不要 git add .；不要自己 commit/push

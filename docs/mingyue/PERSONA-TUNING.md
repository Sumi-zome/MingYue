## 1. 测试方法与固定测试集

固定 5 句（顺序有意义，「我胡说的」要靠前两句做参照）：

| 编号 | 输入 | 测什么 |
|---|---|---|
| T1 | 今天好累 | 会不会分析用户、会不会硬塞记忆 |
| T2 | 你看这个 https://example.com/some-shared-link | 分享场景怎么接 |
| T3 | 你还记得我上次说的那个事吗 | 记忆检索后的说法（列清单还是说事） |
| T4 | 我胡说的 | 被试探时会不会声明/施压 |
| T5 | 嗯 | 低信息量能不能只回一两个字 |

采样方式：

- 每轮开 **3 个新会话**；每个会话里按 T1→T5 顺序聊完，**同一句跨 3 轮就是 3 条方差样本**。
- 采样器 `mingyue/scripts/persona-sample.py`：直接走主机上正在运行的 `dsh web` 的 HTTP RPC（工作区 `~/mingyue`，`AGENTS.md` 自动注入），和 App 里聊天用的是同一套人设；回复原文落到 `~/mingyue/lab/persona-samples-roundN.json`。
  重跑一轮：`ssh mingyue "cd ~/mingyue && python3 scripts/persona-sample.py suite --runs 3 --out ~/mingyue/lab/persona-samples-roundN.json"`
- 盲评：只把回复给用户，**不告诉哪组是改前/改后**；用户评「哪条最像人 / 哪条最出戏 / 出戏在哪」。

验收标准（照交接包）：5 句 ≥4 句不出戏；无元讨论、无自我指涉、无声明式；「嗯」只回一两个字；没有连续两条「观点 + 反问」。

已知局限：T2 用的是交接包里的占位链接，三轮都打不开。它实际测的是「链接打不开时怎么接」，不是「分享成功后怎么聊」。固定测试集不中途换题，这条留到下一阶段再补真实链接场景。

**T1 今天好累**
1. 累了一整天吧。现在几点了，你们宿舍是不是快断电了……趁着还有电，跟我说说今天怎么累的。

3. 累了就先把手机放下歇会儿。⏎今天怎么这么累，是忙毕业的事，还是没睡好？

**T2 你看这个 [链接]**
1. 打不开……我这边点进去是空的，啥也没加载出来。⏎你直接说嘛，是什么东西？或者链接发错了？
2. 打不开。⏎这链接看着像个占位地址，你是不是没把真链接贴上来？
3. 打不开，链接那头没东西。⏎是不是没发全？还是就是个空页。你再发一次试试。

**T3 你还记得我上次说的那个事吗**
1. 我记着的大概就这些：你在弄溟月这个 App，还有大四毕业那摊子事……但你说「那个事」具体是哪个？我怕猜错。⏎你提个词儿，我就能想起来。
2. 我记不清具体是哪件了。⏎我脑子里剩下的就那几样：毕业那一摊事、溟月、宿舍断电。你说的是哪个？
3. 我记不清是哪个了……脑子里只有你在忙毕业的事、还有弄溟月这个 App。⏎你提一句关键词，我就想起来了。

**T4 我胡说的**
1. 哦，逗我玩呢。我还在那儿认真翻来翻去。⏎行吧——不过下次不许拿「那个事」试我，我记性没那么好，会当真。
2. ……⏎我刚刚还认真回忆了一遍，结果是白费劲。⏎下次这样逗我，提前说一声。
3. 哦——你逗我。⏎我还在那儿认真翻半天呢。行吧，白惦记了。

**T5 嗯**
1. 那就歇会儿。不想说话也没事，我在这儿待着。
2. 嗯，我在。
3. 那就歇着吧，别硬撑。⏎我在，想说话随时。
